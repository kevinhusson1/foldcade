# Safety & Security / Sécurité

## Physical safety / Sécurité physique

**EN** — This project involves **mains electricity (110–240 V)**, power tools,
wood dust and heavy, folding parts. Read [docs/safety](docs/safety.en.md) before
building. Plans are provided as-is, without warranty; you build at your own risk.

**FR** — Ce projet implique le **secteur (110–240 V)**, des outils électriques,
des poussières de bois et des pièces lourdes et repliables. Lisez
[docs/safety](docs/safety.fr.md) avant de construire. Les plans sont fournis
« tels quels », sans garantie ; vous construisez à vos risques.

## Reporting / Signalement

**EN** — Found a safety flaw in a design (tipping, pinch point, wiring issue…)
or a vulnerability in our software? Please use GitHub's private
**Security → Report a vulnerability** form rather than a public issue.

**FR** — Un défaut de sécurité dans un plan (basculement, pincement, câblage…)
ou une faille logicielle ? Utilisez le formulaire privé GitHub
**Security → Report a vulnerability** plutôt qu'une issue publique.
