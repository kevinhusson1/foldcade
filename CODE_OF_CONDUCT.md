# Code of Conduct / Code de conduite

**EN** — We want a welcoming, harassment-free community for everyone, whatever
their experience, background or identity. Be respectful, assume good faith,
give constructive feedback and accept it graciously. Unacceptable: harassment,
discrimination, personal attacks, publishing others' private information, spam.
Maintainers may edit or remove contributions and ban repeat offenders. Report
issues privately via the repository's *Security → Report a vulnerability*
channel (see [SECURITY.md](SECURITY.md)). This text is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/).

**FR** — Nous voulons une communauté accueillante et sans harcèlement pour tous,
quels que soient l'expérience, le parcours ou l'identité. Soyez respectueux,
présumez la bonne foi, donnez des retours constructifs et recevez-les avec
élégance. Inacceptable : harcèlement, discrimination, attaques personnelles,
divulgation d'informations privées, spam. Les mainteneurs peuvent modifier ou
supprimer des contributions et exclure les récidivistes. Signalez en privé via
*Security → Report a vulnerability* (voir [SECURITY.md](SECURITY.md)). Texte
inspiré du [Contributor Covenant](https://www.contributor-covenant.org/).
